# Fairy-Stockfish DLL / SO (C API)

The native shared library built from `src/ffishdll.cpp` provides a C ABI. You can call it from C, C++, Rust, Python (`ctypes`), C#, and other environments on Linux, macOS, and Windows (MinGW).

## Features
- Move generation and legal move validation for all supported variants.
- FEN parsing and validation, SAN conversion, game result detection, piece reserve/pocket tracking, and variant metadata.
- Loads variant definitions directly from `variants.ini` at runtime.
- Native build support for GCC, Clang, or MinGW. WebAssembly and Emscripten are not required.

## Building
Run these commands from `src/`:
```
# Linux / macOS (produces libffish.so)
make -f Makefile_dll

# Windows with MinGW (produces ffish.dll)
make -f Makefile_dll EXE=ffish.dll
```

Notes:
- The Makefile disables NNUE embedding by default with `-DNNUE_EMBEDDING_OFF`. To embed NNUE in the library, remove that flag and download the `.nnue` file.
- The build uses `-DLARGEBOARDS -DPRECOMPUTED_MAGICS -DALLVARS` to enable all variants and large boards.

## Linking in your project
### Linux
```
g++ example_dll_usage.cpp -L/path/to/src -lffish -Wl,-rpath,/path/to/src -std=c++17 -O2 -o example
```
Make sure `libffish.so` is in your runtime library path. Use `rpath` as shown above or set `LD_LIBRARY_PATH`.

### Windows (MinGW)
```
# after building ffish.dll and libffish.dll.a in src/
g++ example_dll_usage.cpp -Lpath/to/src -lffish -std=c++17 -O2 -o example.exe
```
Make sure `ffish.dll` is in the executable's folder or on `PATH`. Link against `libffish.dll.a`, the import library generated by `Makefile_dll`.

## C API overview
Key exported functions (see `src/ffishdll.cpp`):
- Initialization: `fsf_init()`
- Board lifecycle: `fsf_new_board(variant, fen, is960)`, `fsf_free_board`
- Moves: `fsf_legal_moves`, `fsf_legal_moves_san`, `fsf_number_legal_moves`, `fsf_push`, `fsf_push_san`, `fsf_pop`; checked batch forms are `fsf_try_push_moves` and `fsf_try_push_san_moves`
- FEN/SAN: `fsf_fen`, `fsf_san_move`, `fsf_variation_san`
- State: `fsf_is_game_over`, `fsf_result`, `fsf_turn`, `fsf_fullmove_number`, `fsf_halfmove_clock`, `fsf_game_ply`
- Material/hand: `fsf_has_insufficient_material`, `fsf_is_insufficient_material`, `fsf_checked_pieces`, `fsf_is_check`, `fsf_is_capture`, `fsf_try_is_capture`, `fsf_pocket`
- Variant/meta: `fsf_available_variants`, `fsf_variant_info`, `fsf_starting_fen`, `fsf_captures_to_hand`, `fsf_validate_fen`, `fsf_board_variant`
- Options/engine info: `fsf_info`, legacy `fsf_set_option_str/int/bool`, checked `fsf_try_set_option_str/int/bool`
- Memory release for returned strings: `fsf_free`

The library allocates all returned `const char*` strings on the heap. Free them with `fsf_free()`.

Legacy batch-push functions stop at the first invalid move and keep the valid
prefix, but do not report how many moves were applied. The `fsf_try_push_*`
forms return `true` only when every move was accepted and write the applied
count to the supplied `int*`; failure still keeps the accepted prefix. The
legacy capture predicate returns false for invalid moves as well as valid quiet
moves. Use `fsf_try_is_capture(board, move, &capture)` to distinguish those
cases. Checked option setters return false for an unknown option; legacy void
setters ignore unknown names.

## Minimal usage
```cpp
fsf_init();
fsf_board b = fsf_new_board("chess", nullptr, false);
const char* moves = fsf_legal_moves(b);
printf("Legal moves: %s\n", moves);
fsf_free(moves);
fsf_push(b, "e2e4");
const char* fen = fsf_fen(b, false, 0);
printf("FEN: %s\n", fen);
fsf_free(fen);
fsf_free_board(b);
```

## Loading custom variants
Read your `variants.ini` content into a string and call:
```cpp
fsf_load_variant_config(iniContent);
```
This reconfigures the variant list (same as in `ffish.js`).

Loading only adds variants. It skips sections for variants that already exist
and does not replace them. To get the number of new variants, use this counting
form:
```cpp
int added = fsf_try_load_variant_config(iniContent);
```
The function returns `0` if it adds nothing. This can happen when sections are
duplicates, use boards that are too large, or are invalid. Check important
variant names with `fsf_available_variants()`.

## Unknown variant names
An empty name, `"Standard"`, or `"standard"` selects `chess`, as in
`ffish.js`. Any other unknown name causes an error; it does not select chess:
- `fsf_new_board` returns `nullptr`; check it before use.
- `fsf_starting_fen` returns an empty string.
- `fsf_captures_to_hand` returns `false`.
- `fsf_validate_fen` / `fsf_validate_position` return `-17`
  (`FEN_INVALID_VARIANT`).
Use `fsf_available_variants()` to list the names this build accepts.

## Threading
`fsf_init()` is thread-safe. Board operations are not synchronized. Use a
separate board in each thread, or use a lock if multiple threads access one
board. Threads may use separate boards at the same time.

Variant configuration and option updates change global engine state. The DLL
serializes these updates with board creation and with each other. Do not change
options or load variant configuration while a thread is using a board. Make
these global changes before you start parallel board operations. All boards in
the process share the resulting variants and options.

## Complete usage example
```cpp
#include <cstdio>
extern "C" {
  typedef void* fsf_board;
  void fsf_init();
  fsf_board fsf_new_board(const char* variant, const char* fen, bool is960);
  void fsf_free_board(fsf_board);
  const char* fsf_legal_moves(fsf_board);
  const char* fsf_fen(fsf_board, bool showPromoted, int countStarted);
  bool fsf_push(fsf_board, const char* uciMove);
  void fsf_pop(fsf_board);
  int fsf_validate_fen(const char* fen, const char* variant, bool is960);
  const char* fsf_available_variants();
  const char* fsf_starting_fen(const char* variant);
  void fsf_free(const char* p);
}

int main() {
  fsf_init();

  const char* variants = fsf_available_variants();
  std::printf("Variants: %s\n", variants);
  fsf_free(variants);

  const char* start = fsf_starting_fen("chess");
  fsf_board b = fsf_new_board("chess", start, false);
  fsf_free(start);

  const char* moves = fsf_legal_moves(b);
  std::printf("Legal (UCI): %s\n", moves);
  fsf_free(moves);

  fsf_push(b, "e2e4");
  const char* fen = fsf_fen(b, false, 0);
  std::printf("After e2e4: %s\n", fen);
  fsf_free(fen);

  fsf_pop(b);
  fen = fsf_fen(b, false, 0);
  std::printf("After undo: %s\n", fen);
  fsf_free(fen);

  int ok = fsf_validate_fen("8/8/8/8/8/8/8/8 w - - 0 1", "chess", false);
  std::printf("Validate empty-board FEN (expect error): %d\n", ok);

  fsf_free_board(b);
  return 0;
}
```
Build:
- Linux: `g++ demo.cpp -L/path/to/src -lffish -Wl,-rpath,/path/to/src -std=c++17 -O2 -o demo`
- Windows (MinGW): `g++ demo.cpp -Lpath/to/src -lffish -std=c++17 -O2 -o demo.exe` (ensure `ffish.dll` is next to the exe or on `PATH`)
